# ANASTASIOU Μετρήσεις v5.3

Πλήρης πηγαίος κώδικας της εφαρμογής μετρήσεων.

## Περιλαμβάνει

- Dashboard: μέτρηση προσφοράς, τελική μέτρηση, ολοκληρωμένα.
- Σύνδεση Γιώργου / Κώστα μέσω Firebase Authentication.
- Κοινό συγχρονισμό έργων μέσω Cloud Firestore.
- 20 γραμμές κουφωμάτων με όλα τα αρχικά πεδία.
- Πέργκολες, κάγκελα, μεσόπορτες, ειδικές κατασκευές.
- Υλικά, πελάτες, αναζήτηση, GPS, κλήση, κοινοποίηση, PDF/εκτύπωση.
- Τοπικές φωτογραφίες ανά έργο.
- Backup/επαναφορά και μεταφορά παλαιότερων τοπικών δεδομένων.
- Βασική φωνητική σημείωση όπου υποστηρίζεται από τον browser.

## Firebase

1. Ανέβασε τα αρχεία στη ρίζα του GitHub repository.
2. Δημοσίευσε τους κανόνες από το `firestore.rules` στη Firestore.
3. Δημιούργησε δύο χρήστες στο Firebase Authentication.

Οι φωτογραφίες παραμένουν τοπικά. Για κοινό συγχρονισμό φωτογραφιών χρειάζεται Firebase Storage.
