# ANASTASIOU Μετρήσεις v5.2

## Τι περιλαμβάνει

- Σύνδεση χρηστών με email/κωδικό.
- Κοινά έργα μέσω Cloud Firestore και ενημέρωση σε πραγματικό χρόνο.
- Τοπικό αντίγραφο και cache για προσωρινή απώλεια σύνδεσης.
- Πλήρης αρχική οθόνη με μετρητές προσφοράς, τελικών μετρήσεων και ολοκληρωμένων έργων.
- Καρτέλες έργων, πελατών, υλικών και backup.
- Κουφώματα, πέργκολες, κάγκελα, μεσόπορτες και ειδικές κατασκευές.
- GPS, πλοήγηση, κλήση πελάτη, κοινοποίηση και εκτύπωση/PDF.
- Οι φωτογραφίες αποθηκεύονται τοπικά στη συσκευή (όχι στο Firebase Storage).

## 1. Firestore rules

Firebase Console → Firestore Database → Rules. Αντικαταστήστε το περιεχόμενο με το `firestore.rules` και πατήστε **Publish**.

## 2. Δημιουργία χρηστών

Firebase Console → Authentication → Users → Add user.

Δημιουργήστε δύο χρήστες με πραγματικά email που ελέγχετε:

- Γιώργος: email + ισχυρός κωδικός
- Κώστας: email + διαφορετικός ισχυρός κωδικός

Μην κοινοποιήσετε τους κωδικούς μέσα στο GitHub ή στο README.

## 3. Ανέβασμα στο GitHub

1. Αποσυμπιέστε το ZIP.
2. Ανοίξτε το repository `anastasiou210979-jpg/anastasiou-measurements`.
3. **Add file → Upload files**.
4. Σύρετε όλα τα αρχεία του φακέλου (όχι το ZIP).
5. Commit message: `ANASTASIOU Measurements v5.1 Firebase sync`.
6. Επιλέξτε commit στο `main` και πατήστε **Commit changes**.
7. Περιμένετε 2–3 λεπτά.
8. Ανοίξτε `https://anastasiou210979-jpg.github.io/anastasiou-measurements/`.
9. Σε υπολογιστή πατήστε `Ctrl+F5`. Σε κινητό κλείστε πλήρως την εφαρμογή και ανοίξτε την ξανά.

## 4. Δοκιμή συγχρονισμού

1. Συνδεθείτε ως Κώστας στη μία συσκευή.
2. Δημιουργήστε δοκιμαστικό έργο και πατήστε **Αποθήκευση**.
3. Συνδεθείτε ως Γιώργος στη δεύτερη συσκευή.
4. Το έργο πρέπει να εμφανιστεί αυτόματα.
5. Πατήστε **Έτοιμο για τελική μέτρηση**. Το στάδιο γίνεται τελική μέτρηση και ο υπεύθυνος Γιώργος.

## Ασφάλεια και περιορισμοί

- Το Firebase API key της web εφαρμογής δεν είναι μυστικός κωδικός. Η προστασία βασίζεται στους κανόνες Firestore και στη σύνδεση χρηστών.
- Οι κανόνες της παρούσας έκδοσης επιτρέπουν πρόσβαση μόνο σε συνδεδεμένους χρήστες.
- Οι φωτογραφίες δεν συγχρονίζονται. Για κοινές φωτογραφίες απαιτείται Firebase Storage και ξεχωριστή πολιτική ασφαλείας.
- Η offline αποθήκευση είναι fallback. Μην επεξεργάζεστε το ίδιο έργο ταυτόχρονα από δύο συσκευές χωρίς σύνδεση, γιατί κατά την επανασύνδεση υπερισχύει η τελευταία αποθήκευση.
